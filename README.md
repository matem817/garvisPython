# Garvis
Garvis is a TelegramBot to tell me and my friend the classes that we have in the morning.
The name is inspired by JARVIS, but I misspelled it and a friend told me to leave it like this so... now is like this.

## Dependencies
- Python 3.8+
- aiogram
## Commands
- /start - /help - Show help message
- /buongiorno - Show morning classes
- /orariodomani - Show tomorrow's classes
- /orarioper - Show classes for a specific day
- /ic - Sets the user's class
- /getlogs - Get the bot logs (admin only)

commands can be modified in the resources/constants/commands.py file.
